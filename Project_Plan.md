# CS211 Group Project - Project Plan

## Project Overview

This project consists of two C++ console applications:

1. A 5x5 version of the game 2048.
2. A program that validates numbers using the Luhn algorithm.

Both programs will be developed using C++17.

## Development Plan

### Phase 1: Project Setup

- Establish the project structure.
- Define development responsibilities.

### Phase 2: Movement Implementation
- Implement movement to the left.
- Implement movement to the right.

### Phase 3: Gameplay Implementation
- Implement scoring.
- Track successful moves.
- Generate random tiles.

### Phase 4: Save and Load
- Implement saving the current game.

- Complete the README.
